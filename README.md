# Plumber Maintenance 24/7 Sharjah (طوارئ سباكة وصيانة عامة الشارقة 24/7)

> **Production-ready, ultra-fast emergency plumbing web application for Sharjah homeowners, building managers, and tenants.**

Built with Next.js 14 (App Router), TypeScript, Tailwind CSS, Lucide React, and next-themes.

---

## 🚨 Key Features

- **24/7 Direct Emergency Dispatch:** Instant 1-tap phone calls to `+971 56 388 9560` and pre-filled WhatsApp SOS messaging.
- **Interactive Emergency Triage:** Step-by-step diagnostic selector calculating instant ETAs across Sharjah suburbs (Al Nasiriyah, Al Majaz, Al Nahda, Muwaileh, etc.) with safety first-aid instructions.
- **Bilingual & Bi-directional (AR ⇄ EN):** Dynamic `<html dir="rtl|ltr">` with native Cairo (Arabic) and Inter (English) typography.
- **Zero Hydration Light & Dark Mode:** Powered by `next-themes` with semantic dual classes.
- **Local SEO & Schema.org:** Google-compliant JSON-LD structured data with GPS coordinates `(25.3622, 55.3912)`, 24/7 operating hours, review schema (4.8★), and service catalog.
- **Sticky Mobile Dispatch Dock:** High-z-index floating bottom dock on mobile viewports for thumb-reach access.

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
